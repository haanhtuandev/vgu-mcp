### VGU MCP SERVER

This project is written to enable VGU students to interact with VGU-specific platforms such as Moodle, SIS, and so on using AI agents.

Imagine if you can tell Codex or Claude or OpenCode "yo, what assignments do i have coming up?" or "hey summarize the lectures from week 1 to week 6" or even "do assignment in operating system for me then submit it"

That would be damn cool isnt't it? I, myself love utilizing LLMs to study, and the chatbots are incredible at helping me understand a concept or giving me quizzes to do. But, in order to do that accurately, I need to provide

a lot of context regarding my study, and that's a little annoying. Having learnt about MCP servers, I will attempt to write the arms and legs for the LLM brain to become my actual learning assistant. Let's see how it turns out.

Since this project can help a lot of students, I hope they find it cool and useful, and i hope future students will maintain this codebase, and we can all collaborate to build more tools for the MCP server. Let's go.

To state it out right this very moment, i can explain that the MCP server simply exposes: initialize endpoint - this is what will be called by the MCP client (in this case it is OpenCode). So the flow would be something like this


user prompts "what class do i have?" -> the LLM inside OpenCode translate user's message into a tool call -> decides to call getCoursesTool -> a HTTP client (or something) fires a request to our MCP server
-> the request is routed to the correct handler -> which fires a request to Moodle website -> get the return courses -> respond to OpenCode -> Opencode parses the response -> LLM use response to answer user
